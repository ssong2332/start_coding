Claude Code 메인 세션(데스크톱 앱) 전용 절차다. 언제 별도 세션을 쓰는지는 AGENTS.md "메인 세션과 서브에이전트 구분" 표의 "별도 세션" 행이 정한다. 서브에이전트(대화 안에서 끝나는 호출)와 다르다 — 서브 세션은 사용자가 열어 볼 수 있는 독립 세션이다.

| 단계 | 규칙 |
|---|---|
| 생성 | 메인 세션이 판단해 제안하고 사용자 승인으로 시작한다. 파일을 쓰는 세션은 worktree로 격리한다. 지시문에 역할 원본 경로·범위·완료 조건·오늘 날짜·근거(사용자 답변은 축어 인용)를 적는다 |
| 보고 | 서브 세션은 마지막 메시지를 보고 템플릿으로 끝낸다(브랜치 이름·명령 원문·종료 코드·증거 경로 포함). docs/Tasks.md 상태는 바꾸지 않는다 |
| 검증 | 보고는 근거이지 증명이 아니다. 메인 세션이 diff로 범위 밖 변경을 확인하고 통과 주장은 재실행해 대조한다. 재실행하지 못한 항목은 `미검증` |
| 제공 | 메인 세션이 결과를 사용자에게 전달하고, 화면이 있으면 AGENTS.md "사용자 화면 확인"을 거친다 |
| 정리 | 사용자와 메인 세션의 검증을 모두 통과하고 브랜치가 병합(또는 폐기 결정)된 뒤, 사용자 승인을 받아 서브 세션을 **보관**하고 worktree를 정리한다. 영구 삭제는 사용자가 명시적으로 지시할 때만 한다(대화 근거가 사라진다). 정리 전에 worktree 안의 `.artifacts/` 증거가 작업 종료까지 보존돼야 하면 메인 체크아웃으로 옮겼는지 확인한다 |
