# Codex UI 구현·확인

웹 UI를 새로 만들거나 수정할 때 읽는다. CLI·백엔드만 바꾸는 작업에는 적용하지 않는다. 기능·화면 상태·소유권·승인·심각도·필수 검사는 공통 원본을 따른다.

## 구현 전에 시각 방향을 정한다

- 새 UI의 목적, 주 사용자, 가장 자주 할 일, 첫 화면에서 우선할 정보와 행동을 정한다. 기존 인터뷰·PRD 답을 재사용한다.
- 기존 화면을 고칠 때는 현재 스타일·토큰·컴포넌트·실제 내용을 먼저 읽는다. 사용자 요청이 재설계가 아니라면 기존 정체성을 유지한다.
- 설계 시 architect는 기존 Architecture의 UI 부분에 배치, 색상 역할, 글꼴과 크기 위계, 간격, 컴포넌트 상태를 간결하게 기록한다. 사용자 참고 화면이 있으면 무엇을 따를지 명시한다.
- 구현 중 세부 표현은 승인된 기능·설계 범위에서 결정한다. 새 화면·기능·데이터·인터페이스 변경은 기존 변경 요청 절차로 보낸다. 시각 지침만으로 별도 승인 게이트를 만들지 않는다.

## 실제 제품에 맞게 구현한다

- 목적에 맞는 정보 위계와 입력 흐름을 만든다. 개인 기록 앱에는 탐색·기록의 편의가, 소개 페이지에는 내용을 이해하고 행동하는 흐름이 우선이다.
- 색·글꼴·간격·상태는 소수의 일관된 토큰과 기존 컴포넌트를 사용한다. 같은 크기의 박스, 큰 빈 여백, 장식용 수치가 내용을 대신하게 두지 않는다.
- 제목·메모·목록·긴 입력·빈 상태처럼 실제 사용할 내용을 넣어 배치를 확인한다. 예시 내용과 실제 데이터, 만든 그래픽과 실제 자산을 구분해 표시한다. 근거 없는 통계·후기·표지·성과를 만들지 않는다.
- 성공·오류·빈 상태·로딩·disabled·초점은 해당 작업에 배정된 범위에서 구현한다. 오류는 문제와 복구 방법을, 빈 화면은 가능한 다음 행동을 보여준다.
- 새 글꼴·이미지·컴포넌트·모션 라이브러리는 필요한 경우에만 현재 설치·네트워크·라이선스·권한 범위에서 선택한다. 장식을 위해 설치를 전제하지 않는다.
- 외부 디자인 스킬은 실제 제공 여부와 해당 용도를 확인해 선택한다. frontend-design은 시각 방향, impeccable은 요청에 맞는 비평·개선에 도움이 될 수 있다. 선택한 스킬의 절차를 조용히 생략하지 않으며, 중복 인터뷰·추가 도구·게이트 충돌이 있으면 기존 승인과 공통 규칙을 확인해 처리한다.

## 화면으로 확인한다

| 조건 | 확인 |
|---|---|
| UI를 변경함 | 현재 사용 화면 크기와 변경 영향을 받는 데스크톱·좁은 화면에서 직접 사용한다. 빌드 성공이나 캡처 파일 존재만으로 통과하지 않는다 |
| 목록·상세·폼을 변경함 | 긴 제목·메모·여러 항목·빈 결과에서 넘침, 잘림, 읽는 순서와 주요 행동의 발견 가능성을 확인한다 |
| 대화상자·패널을 변경함 | 실제 폭·높이·내부 스크롤, 진입·오류·닫기 후 초점, 키보드 조작을 확인한다. viewport 설정값만 믿지 말고 DOM에서 실제 크기를 확인한다 |
| 접근성을 확인함 | web-performance의 공통 필수 기준에 따라 label·아이콘 이름·키보드·대비를 확인한다. 모션을 추가하면 reduced-motion도 확인한다 |
| 디자인을 수정함 | 정한 시각 방향과 실제 화면을 대조하고 근거 있는 차이를 한 묶음으로 수정한다. 새 발견 없이 끝없이 다듬지 않는다 |
| 검사기가 제한적으로 동작함 | 파서 부재·DEGRADED·지원하지 않는 항목을 기록한다. 정규식 발견 0건이나 일부 대비 측정을 전체 디자인·접근성 통과로 보고하지 않는다 |

브라우저 가용성·메인 세션의 대리 확인·실패·재실행 불가 수용은 AGENTS.md와 DoD를 따른다. reviewer는 읽기 전용으로 설계·화면 근거를 대조하고, QA는 실제 실행 여부와 인용을 구분한다. 주관적 선호만으로 치명 결함을 만들지 않고, 동작·접근성·승인 기준의 결함과 시각 개선 권고를 구분한다.

## 기록

기존 보고 형식에 실행 주체·시각·URL·실제 화면 크기·AC별 관찰·콘솔 결과와 증거 경로를 붙인다. 캡처는 실제 화면 관찰을 보조한다. 디자인 적합성, 기능 테스트, 접근성, 사용자 취향 승인을 서로 대신하지 않는다.
