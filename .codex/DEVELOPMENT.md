# Codex 개발 보조 지침

AGENTS.md와 .agents/roles/의 공통 원본이 업무·권한·승인·완료 기준을 정한다. 이 문서는 Codex에서 그 기준을 수행하는 방법을 보완한다. 별도 파이프라인이나 추가 승인 단계가 아니다.

## 역할별로 필요한 부분만 적용

| 역할 | 이번 작업에서 사용할 부분 |
|---|---|
| planner | 이미 확정된 인터뷰 답변을 재사용하고, 기능·오류·빈 상태의 검증 담당을 작업에 배정한다. 미확정 사항만 질문한다 |
| architect | 현재 버전·실행 수단을 근거로 설계한다. UI가 있으면 FRONTEND.md의 시각 방향을 기존 Architecture에 기록한다 |
| implementer | 아래 원인 분석·개발 중 검사와 EXECUTION.md를 사용한다. UI 변경이면 FRONTEND.md를 읽는다 |
| reviewer | 변경분의 정확성·보안·데이터 손실·설계 일치를 먼저 검토한다. UI 변경이면 FRONTEND.md의 의도와 실제 화면 근거도 대조한다 |
| quality_assurance | 정의된 필수 검사를 실행하고 자기 실행과 인용을 구분한다. UI 변경이면 FRONTEND.md의 화면·접근성을 실제 확인한다 |
| docs | 실제 diff·결정·검증 명령·미해결 사항을 소유 문서에 반영한다. 예상 동작이나 다른 역할의 주장을 실행 사실로 바꾸지 않는다 |

## 코드 탐색과 문서 조회

- 먼저 담당 작업·기존 구현·관련 테스트·검증된 명령을 좁혀 읽는다. 텍스트·파일 검색은 rg를 우선하고, 심볼 도구는 실제 제공될 때 사용한다.
- 외부 API·라이브러리의 변경 가능한 사용법은 프로젝트가 쓰는 버전의 공식 문서로 확인한다. OpenAI 제품은 사용 가능한 openai-docs를 따른다.
- Context7 등 문서 도구는 현재 제공되고 권한이 확인됐을 때만 사용한다. 목록에 적혀 있다는 이유로 연결·인증·버전 일치를 가정하지 않는다.
- 별도 MCP·클라우드·DB·결제·배포 도구는 해당 프로젝트가 필요로 할 때 선택한다. 범용 팩 전체 설치나 추가 로그인은 이 지침의 전제가 아니다.

## 원인 분석

오류를 보고한 뒤 기존 승인 범위 안에서 진행 가능한 조사를 구분한다. 우회 승인·동일 실패 반복 제한은 AGENTS.md를 그대로 따른다.

1. 실제 오류, 재현 조건, 마지막 정상 동작을 확보한다. 환경·권한·도구 실패와 제품 코드 실패를 구분한다.
2. 관찰 사실과 가설을 분리한다. 가설마다 이를 구별할 수 있는 가장 작은 확인 방법을 정한다.
3. 확인 결과에 근거해 원인을 좁힌다. 테스트 시간 초과만으로 머신 부하를 단정하거나, 제한 시간 증가만으로 해결을 보고하지 않는다.
4. 버그 수정은 공통 TDD 절차의 실패하는 재현 테스트와 함께 수행한다. 무관한 리팩토링을 끼워 넣지 않는다.
5. 보고에는 확인한 원인·근거·아직 모르는 부분·다음 확인을 남긴다. 해결하지 못한 것을 수정 완료로 바꾸지 않는다.

## 개발 중 검사와 완료 검사

- 개발 루프에서는 변경 경계의 단위·통합 테스트를 먼저 돌려 피드백을 얻고, 전환 전에는 Tasks·Architecture·DoD가 요구하는 검사 전체를 수행한다.
- UI의 실제 사용 흐름은 브라우저에서 확인한다. 반복 회귀가 필요한 핵심 흐름에는 프로젝트에서 승인한 E2E 러너를 사용한다. 세션의 브라우저 조작과 저장소의 자동 테스트를 구분한다.
- 타입 검사·린트·포맷·의존성·보안 검사는 프로젝트 스택·설계·설정에 따라 적용한다. 이미 설정된 필수 검사는 생략하지 않는다. 새 설치나 설정 변경은 기존 권한·설계 범위를 확인한다.
- 포맷 명령을 실행하기 전에 규칙·가드·문서 보호 경로의 제외 설정을 확인한다. 이 지침 때문에 공통 설정을 임의 편집하지 않는다.
- 한 번 충분히 확인한 뒤에는 구체적인 남은 위험이나 필수 게이트 없이 검사를 늘리지 않는다. 공통 필수 테스트와 실패 처리 규칙은 축소하지 않는다.

## 보고와 핸드오프

별도 영구 메모리나 문서를 자동 생성하지 않는다. 기존 소유 문서·증거와 핸드오프 보고를 재사용한다. 확정된 요구·결정, 바뀐 파일, 실제 실행 명령·종료 상태·증거 경로, 미해결 문제, 다음 담당을 전달한다. 타인의 원문 전달·인용 표시는 AGENTS.md를 따른다.

설정 파싱·정적 검사 통과와 실제 앱에서의 역할 로드·기능·화면 확인을 별개로 보고한다. 추가 안내 파일은 자동 실행되는 가드가 아니며, 명시적으로 연결된 역할이 읽는 지침이다.
