# Codex 실행 결과 수집

이 문서는 Codex에만 적용한다. 공통 판정·증거 보존·소유권은 AGENTS.md가 원본이다.

| 반환 상태 | 다음 행동 |
|---|---|
| exec_command 결과에 session_id가 있고 종료 코드가 없음 | 명령은 실행 중이다. write_stdin에 해당 session_id를 넘겨 새 출력을 모으고 종료 코드를 확인한다. 빈 출력은 실패나 완료의 증거가 아니다 |
| functions.exec가 Script running with cell ID를 반환 | functions.wait에 그 cell_id를 넘겨 이어받는다. 명령의 session_id와 혼용하지 않는다 |
| 명령이 종료됨 | 최초 출력과 모든 후속 출력을 합쳐 보존하고 실제 종료 코드를 기록한다. 잘린 부분은 미검증으로 표시한다 |
| 도구 오류 또는 같은 실패 2회 | AGENTS.md의 오류·반복 실패 규칙에 따라 보고한다. 미완료 실행을 성공으로 판정하지 않는다 |

이름이 비슷한 대기 API를 추측해서 호출하지 않는다. 현재 세션에 제공된 도구 계약을 확인한다. 결과를 모으기 위해 검증된 빌드·테스트 명령 원문을 임의로 바꾸지 않는다. 출력 수집 방식과 명령 원문은 별도로 기록한다.
